# ゲームUI要件定義

## 1. ゲームに必要なUI要素一覧

1. タイトル画面
   - ゲームタイトル
   - スタートボタン
   - オプション/設定ボタン
   - クレジット/スタッフ表示
2. メインメニュー
   - 新規ゲーム
   - 続きから
   - 設定
   - 終了
3. ゲームプレイ画面
   - スコア表示
   - 各アクションボタン(ドロー，オープン，リーチ，チェック，テトラージュ)
   - タイマー・制限時間
   - 所持カード
   - プレイヤー名
   - チュートリアル・ヒント表示
   - ポーズボタン
4. ポーズ・一時停止メニュー
   - 再開
   - 設定
   - タイトルに戻る
5. 設定画面
   - 音量調整（BGM/SE/ボイス）
   - 画面設定（解像度、ウィンドウ/フルスクリーン）
   - 操作設定（キーコンフィグ）
   - 言語設定
6. リザルト・ゲームオーバー画面
   - スコア・成績表示
   - リトライ/再挑戦ボタン
   - タイトルに戻るボタン
   - 次のバトルに進むボタン
7. ダイアログ・ポップアップ
   - 確認メッセージ（例：本当に終了しますか？）
   - エラーメッセージ
   - チュートリアル・説明ウィンドウ
8. その他
   - ローディング画面
   - セーブ/ロード画面
   - プロフィール・ステータス画面
   - チャット・メッセージウィンドウ（マルチプレイの場合）
