# UI実装のための共通システム設計

## 1. 作るべきシステム一覧

1. **画面遷移システム**#完成 
   - 画面（タイトル、ゲームプレイ、リザルト等）の切り替えを管理 
2. **ボタン・インタラクションシステム**
   - ボタン表示・押下・状態管理、タッチ/クリック対応
3. **ダイアログ・ポップアップシステム**#完成 
   - 確認・エラー・説明などの一時的なウィンドウ表示 
4. **カード表示・操作システム**
   - 手札・場札の表示、カード選択・並び替え・出す操作
5. **プレイヤー情報表示システム**
   - プレイヤー名、スコア、手札枚数、状態（アクティブ/パス等）の表示
6. **アクションボタンシステム**
   - ゲーム進行に必要な各種アクションボタンの表示・制御
7. **タイマー・進行状況システム**
   - 制限時間やターン、ラウンド進行の表示・管理
8. **メッセージ・ヒント・ヘルプシステム**
   - チュートリアル、ヒント、ルール説明の表示
9. **プロフィール・設定システム**
   - プレイヤー名、プロフィール、各種設定（音量、明るさ等）の管理
10. **チャット・コミュニケーションシステム**
    - マルチプレイ時のチャット・エモート
11. **ローディング・セーブ/ロードシステム** #完成 
    - ローディング画面、セーブ/ロードデータ管理
