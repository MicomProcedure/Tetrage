# ゲームUI要素の一般的な要件定義

## 1. タイトル画面
### 1. 対象UIの特定
- ゲームタイトル
- スタートボタン
- オプション/設定ボタン
- クレジット/スタッフ表示

### 2. 目的・ゴール
- ゲームの開始や設定など、最初の導線を提供し、世界観を伝える。

### 3. 表示要素
- ゲームタイトルロゴ
- スタートボタン
- オプション/設定ボタン
- プロフィール設定
- クレジット/スタッフ表示
- バックグラウンド画像やアニメーション

### 4. 操作とインタラクション
- スタートボタンを押すとゲーム開始
- オプション/設定ボタンで設定画面へ遷移
  - 設定画面内容 
    - BGM音量
    - SE音量
    - 明るさ設定
    - 言語設定
    - 配信者モード
- プロフィール設定
  - 名前
  - 自分の名前を表示するかどうか
  - 相手の名前を表示するかどうか
- クレジット/スタッフ表示でスタッフ情報を表示
  - 名前をタップしたらそれぞれのスタッフのSNSに飛ぶようにしたい
- マウスクリック、タッチ操作に対応


## 2. ゲームプレイ画面
### 1. 対象UIの特定
- スコア表示
- 各アクションボタン（ドロー，オープン，リーチ，チェック，テトラージュ）
- タイマー・制限時間
- 所持カード
- プレイヤー名
- チュートリアル・ヒント表示
- ポーズボタン

### 2. 目的・ゴール
- ゲーム進行に必要な情報と操作手段をリアルタイムで提供する。

### 3. 表示要素
- 現在のスコア
- アクションボタン群
- 残り時間やタイマー
- 所持カード一覧
- プレイヤー名
- チュートリアル・ヒントテキスト・ヘルプボタン
- ポーズボタン

### 4. 操作とインタラクション
- アクションボタンを押して各種操作を実行
  - リーチ前
    - ドロー:ドローした2枚のカードのうちどちらを手に戻すかの選択画面
    - オープン:どのカードをオープンするかの選択画面
      - カードをタップした後に，このカードをオープンしますか？「はい」「いいえ」
    - テトラ―ジュ:マルチorソロの選択画面
      - マルチ:マルチする相手の選択画面
        - マルチしますか「はい」「いいえ」
    - リーチ:リーチしますか？「はい」「いいえ」
  - リーチ後
    - チェック:どのプレイヤーをチェックするかを選択
      - このプレイヤーをチェックしますか？「はい」「いいえ」
    - テトラ―ジュ:ソロテトラ―ジュをしますか？「はい」「いいえ」
- ポーズボタンで一時停止
  - 再開ボタン
  - 設定ボタン
  - タイトルに戻るボタン
- マウス、タッチで操作


## 3. リザルト・ゲームオーバー画面
### 1. 対象UIの特定
- スコア・成績表示
- リトライ/再挑戦ボタン
- タイトルに戻るボタン
- 次のバトルに進むボタン

### 2. 目的・ゴール
- ゲーム結果を明示し、次の行動（再挑戦・終了・次バトル）を選択させる。

### 3. 表示要素
- スコアや成績
- 各種ボタン
- 達成演出やメッセージ

### 4. 操作とインタラクション
- 各ボタンで該当操作を実行
- マウス、タッチで選択・決定

## 4. ダイアログ・ポップアップ
### 1. 対象UIの特定
- 確認メッセージ（例：本当に終了しますか？）
- エラーメッセージ
- チュートリアル・説明ウィンドウ

### 2. 目的・ゴール
- 重要な確認やエラー、説明を一時的に表示し、ユーザーの判断や理解を促す。

### 3. 表示要素
- メッセージテキスト
- OK/キャンセルなどのボタン

### 4. 操作とインタラクション
- ボタンで選択・決定
- 表示中は他の操作を制限
- マウス、タッチで操作

## 5. その他
### 1. 対象UIの特定
- ローディング画面
- セーブ/ロード画面
- プロフィール・ステータス画面
- チャット・メッセージウィンドウ（マルチプレイの場合）

### 2. 目的・ゴール
- ゲーム進行や情報管理、コミュニケーションを円滑にする。

### 3. 表示要素
- ローディング進捗バーやヒント
- セーブデータ一覧
- プレイヤー情報
- チャット欄・入力欄

### 4. 操作とインタラクション
- セーブ/ロードデータの選択・決定
- チャット入力・送信
- マウス、タッチで操作
